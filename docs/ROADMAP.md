# Roadmap

v10.0 之后的计划。10.x 是长期支持（LTS）版本线：10.x 内每个次版本都保持向后兼容（配置 schema v10 不变），
活跃支持至 2027-10-31，安全维护至 2028-10-31。v11.0 是下一个破坏性版本。（9.x → 10.0 的计划已全部完成，见 [CHANGELOG](../CHANGELOG.md)。）

- v10.1：内核插件 SDK：用同一套接口编写功能模块（配置 schema、管理路由、调用钩子），支持第三方模块热加载与隔离
- v10.2：多智能体编排 2.0：跨网关的智能体任务图、检查点与断点续跑，失败步骤自动重试与补偿
- v10.3：工具调用的实时成本与碳排放预算：按租户 / 智能体设定预算，超限前预警、超限后降级或拒绝
- v10.4：隐私计算：工具结果的差分隐私聚合与联邦查询，敏感数据不出域
- v10.5：全链路回放与时间旅行调试：基于事件溯源存储重放任意时刻的网关状态与调用
- v10.6：策略即代码 2.0：Rego / Cedar 策略、策略单元测试与变更影响分析
- v10.7：边缘自治：边缘节点断网时本地决策（策略、缓存、WASM 工具），恢复后自动对账
- v10.8：后量子身份：ML-DSA 证书与签名（插件、工具清单、审计日志），混合证书平滑过渡
- v10.9：v11 弃用警告与 `migrate --to 11`
- v11.0：（破坏性）配置 schema v11、模块化内核默认按需加载、移除 10.x 弃用项、迁移指南
